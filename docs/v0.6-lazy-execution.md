# v0.6 — Executable lazy graphs

v0.6 turns ordinary graph data into an optimized, executable CPU schedule.

## Added

- Constant folding for operations with constant parents.
- CSE that retains duplicate names as explicit alias nodes.
- Output-specific dead-code elimination after optimization.
- Elementwise fusion groups and ordered load/kernel/fusion steps.
- `executeCpu.with:` as a pure-Arturo reference backend.

## Contract

`scheduleGraph graphData output` freezes a parameter snapshot and returns ordinary data. Execution requires feeds for every reachable input and returns an owned tensor. `.all` also returns intermediate values and the schedule.
