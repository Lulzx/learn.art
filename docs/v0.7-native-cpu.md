# v0.7 — Native CPU kernels

v0.7 lowers eligible elementwise fusion groups to generated C and calls them through Arturo’s native-library interface.

## Added

- `compileNativeCpu` with optional compiler and build-directory controls.
- `executeNativeCpu` with automatic reference fallback.
- One-call tensor CSV ABI for zero, one, or two external kernel inputs.
- Shape guards, compiler fallback, parity tests, and a native benchmark.

## Boundary

Native kernels return the group’s single live output. Groups with more than two external tensors, non-scalar inline constants, multiple live outputs, zero-sized tensors, unsupported platforms, or runtime shape changes use `executeCpu` semantics.
