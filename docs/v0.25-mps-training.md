# v0.25 MPS training

v0.25 adds a compiled two-layer MLP trainer whose forward pass, categorical cross-entropy gradient, ReLU backward pass, SGD updates, and next-step parameters remain in Metal storage. CPU tensors may seed a step, but GPU-resident batches and parameters need no upload or gradient download between iterations.

The MNIST path loads normalized IDX image bytes and class bytes directly through `arturo-metal`, slices batches on device, and evaluates through a separate reusable inference executable. The checked-in example uses a 100-sample batch, 784 inputs, 128 hidden units, 10 classes, and one epoch.

This milestone also adds CPU reference implementations and scheduled MPS lowering for NCHW `conv2d`, `maxPool2d`, and `avgPool2d`. Their forward behavior is available in ordinary learn graphs; reverse-mode convolution and pooling gradients remain explicit future work.
