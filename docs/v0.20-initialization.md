# v0.20 — Reproducible initialization

v0.20 replaces implicit global randomness in composed layers with explicit initializer objects and isolated deterministic streams.

## Strategies

```arturo
xavier: initializer.seed: 41 'xavier
he: initializer.seed: 42 'he
uniform: initializer.seed: 43.low: (0.0 - 0.1).high: 0.1 'uniform
zeros: initializer 'zeros
```

`initializeTensor spec shape` creates an owned CPU tensor. Its linear-congruential stream is local to the call, so the same initializer and shape always produce identical data regardless of unrelated random calls.

Xavier uniform uses `sqrt(6 / (fanIn + fanOut))`; He uniform uses `sqrt(6 / fanIn)`. For matrices, the first and last dimensions are the input and output fans. Higher-rank shapes multiply intervening dimensions into both fans. Fan strategies reject scalar and zero-fan shapes.

## Layer construction

`denseLayer` now defaults to Xavier with seed `0` and zero bias. Pass an initializer to make the choice explicit:

```arturo
encoderInit: initializer.seed: 10 'he
headInit: initializer.seed: 11 'xavier
encoder: denseLayer.name: "encoder".initializer: encoderInit 4 8
head: denseLayer.name: "head".initializer: headInit 8 3
```

Use distinct seeds for independent same-shaped layers. `.zeros` and `.initializer:` are intentionally mutually exclusive.

## Reset and metadata

`resetParameter parameter spec` regenerates its current shape and clears its gradient. `resetLayer` applies the requested strategy to weights and zeros to bias. `resetParameters` accepts a graph, layer, or explicit parameter block.

Every reset parameter stores an owned `learn.initializer-state` dictionary in its graph context. `initializerState` and `initializerFromState` validate and reconstruct the strategy itself. Model checkpoints continue to store realized parameter values, which is the authoritative state for resuming training.
