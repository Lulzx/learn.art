# v0.8 — Tensor generalization

v0.8 removes the rank-two ceiling while keeping tensors dense, contiguous, and owned.

## Added

- Recursive rectangular shape inference for nested Arturo blocks.
- Row-major strides and trailing-dimension broadcasting at any rank.
- `tensorSum.axis:` and `mean.axis:` with negative-axis normalization.
- `transpose.axes:` for explicit permutations; plain `transpose` swaps the final two axes.
- `tensorAt` for checked scalar indexing with negative indices and owned results.
- Reverse-mode rules for axis reductions, permutations, indexing, and arbitrary-rank unbroadcasting.
- Graph metadata and reference CPU execution for every new operation.

## Boundary

`matmul` remains rank-2. `tensorAt` returns a scalar copy rather than a view, and v0.8 does not add slicing or public in-place tensor mutation.
