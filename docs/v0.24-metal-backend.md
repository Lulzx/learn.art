# v0.24 Metal backend

v0.24 turns device placement into a registry and adds an optional MPS adapter backed by the public `arturo-metal` repository.

Build the pinned submodule from `vendor/metal`, then import `src/metal-backend.art`. `compileMps` lowers an optimized learn schedule into one reusable MPSGraph executable; `executeMps.with:` accepts CPU or MPS feeds and returns an MPS-owned learn tensor. Frozen parameters remain on the GPU until `releaseMps`.

The adapter covers broadcast arithmetic, dense and batched matrix multiplication, activations, reshape/transpose, reductions, softmax, deterministic dropout, and categorical cross entropy. The ordinary CPU entry point does not load Metal, so non-macOS use remains unchanged.
