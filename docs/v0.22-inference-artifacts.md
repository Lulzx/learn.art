# v0.22 — Portable inference artifacts

v0.22 packages an optimized graph snapshot, realized parameter values, one selected output, and optional fitted preprocessing into an immutable executable artifact.

## Compile and run

```arturo
artifact: compileInference model 'prediction
result: runInference.with: #[x: features] artifact
```

Compilation temporarily switches the graph to evaluation mode so dropout becomes identity, captures ordinary graph data, then restores the caller's original mode. Optimization prunes unreachable nodes before constant folding, so labels, losses, and unsupported training-only branches cannot interfere with a prediction output.

Parameters are copied into graph data. Later model updates do not change an existing artifact.

## Frozen preprocessing

```arturo
artifact: compileInference
              .preprocessor: fittedScaler
              .input: 'x
              model 'prediction
```

The fitted transform is reconstructed from owned state during compilation. `runInference` copies the supplied feed dictionary, transforms only the configured input, and leaves caller data unchanged. If `.input:` is omitted, the first reachable graph input is selected; specifying an input without a preprocessor is rejected.

## Safe file format

```arturo
saveInference artifact "model.learn-inference"
loaded: loadInference "model.learn-inference"
```

Header `10022` contains a recursively tagged representation of the `learn.inference-state` dictionary. The codec distinguishes nulls, logicals, integers, floats, strings, literals, blocks, and dictionaries. Text is stored as numeric character codes so Arturo parsing cannot reinterpret versions or dotted names as code tokens.

Loading decodes and validates graph data, reconstructs preprocessing, and rebuilds the optimized reference CPU schedule. The file is parsed as data and never executed.

`inferenceState` returns an owned ordinary dictionary suitable for inspection. Mutating it cannot affect the artifact.
