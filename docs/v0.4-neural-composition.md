# v0.4 — Neural composition

v0.4 makes multilayer differentiable programs possible without adding a second runtime.

## Added

- Differentiable `relu` and `tensorTanh` activations.
- Stateful Momentum and Adam optimizers.
- `dense input weight bias` composition.
- `fit.mlp.hidden:` for a one-hidden-layer dense regression graph.

## State

Optimizer moments live outside models. MLP weights remain ordinary named graph parameters, so inspection, forwarding, and differentiation use the same machinery as scalar regression.
