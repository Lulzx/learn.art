# v0.17 — Multiclass learning

v0.17 adds numerically stable categorical probabilities and loss, their reverse-mode gradients, shaped graph placeholders, and class metrics.

## Stable probabilities and loss

`softmax` operates across the final axis and subtracts each row's maximum before exponentiation. It accepts tensors or differentiable values and preserves shape.

`crossEntropy logits targets` accepts a class vector or a sample-by-class matrix. Targets are zero-based integer class indices: a scalar for one sample or a vector with one entry per row. The implementation computes log-sum-exp directly, so large logits do not overflow.

The cross-entropy backward pass is fused as `(softmax(logits) - oneHot(targets)) / samples`. Targets may be graph inputs but cannot require gradients.

## Matrix graph declaration

Ordinary `input` remains a dynamic scalar placeholder. Operations such as `matmul` need a compatible shape when the graph is first declared, so `inputShape` provides an initial shape without constraining future batch sizes:

```arturo
model: graph [
    x: inputShape [1 2]
    y: input
    weight: parameter.zeros [2 3]
    bias: parameter.zeros [3]
    linear: matmul x weight
    logits: linear + bias
    loss: crossEntropy logits y
]
```

`forward.with:` may later feed `x` with any leading batch size compatible with its two feature columns.

## Prediction and execution

`classPrediction` removes the final axis and returns floating-point class indices, matching learn's float64 tensor contract. Ties choose the first class. `multiclassAccuracy` requires equal target and prediction shapes and integer-valued entries.

Softmax and cross entropy are supported by eager recomputation and the reference scheduled CPU executor. They remain non-fusible reduction operations, so native schedules safely route them through the reference step.
