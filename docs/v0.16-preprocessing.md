# v0.16 — Fitted preprocessing

v0.16 adds immutable fitted standardization and reversible preprocessing pipelines. Their state is ordinary Arturo data and has a safe positional checkpoint representation.

## Fit and apply

```arturo
scaler: standardScaler xTrain
xTrainScaled: applyTransform scaler xTrain
xTestScaled: applyTransform scaler xTest
```

Statistics are fitted independently for every position in the trailing feature shape. The leading axis is always the observation axis. A zero-variance feature receives scale `1.0`, producing zeros while remaining invertible.

`applyTransform` returns a new tensor with the input shape and device. The fitted object and source tensor are never mutated. `inverseTransform scaler scaled` reconstructs the original units.

## Pipelines

A pipeline contains already-fitted steps and applies them in declaration order:

```arturo
firstOutput: applyTransform firstScaler xTrain
secondScaler: standardScaler firstOutput
pipeline: transformPipeline @[firstScaler secondScaler]
```

Inverse transformation traverses those steps in reverse order. Pipelines can be nested, which leaves room for additional fitted transform types without changing composition semantics.

## Portable state

`preprocessorState` returns an owned `learn.preprocessor-state` dictionary. `preprocessorFromState` validates and reconstructs either a scaler or a nested pipeline.

```arturo
savePreprocessor pipeline "features.learn-state"
restored: loadPreprocessor "features.learn-state"
```

The file is parsed as data and uses header `10016`; it is never evaluated as Arturo code. Feature shape, statistics, step order, and device placement are validated before construction.
