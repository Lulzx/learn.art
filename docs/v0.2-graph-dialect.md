# v0.2 — Graph dialect

v0.2 moved the product surface from an eager learning demo to an input-driven Arturo dialect.

## Added

- `input` placeholders and `forward.with:` feeds.
- Scalar parameters such as `parameter 0.0`.
- Stable IDs for differentiable nodes; structural equality is not node identity.
- `inputs`, `parameters`, `operations`, `graphData`, and `explain`.
- A plain dictionary graph representation with roles, shapes, operations, and parents.

## Invariant

Runtime objects execute the graph, but `graphData` is the portable ordinary-data representation. Later visualization, rewriting, serialization, and compilation build on that representation.
