# v0.5 — Graph transformations

v0.5 begins the lazy-runtime path at the ordinary-data boundary.

## Added

- `validateGraphData` for ordered graph integrity checks.
- `deadCodeEliminate` and `optimizeGraph` for output-reachable graph data.
- `commonSubexpressions` for safe duplicate discovery.
- `graphDot` for Graphviz-compatible visualization.

## Boundary

Transforms operate on `graphData`, not live autograd objects. v0.5 reports common subexpressions but preserves named nodes; executable fusion, scheduling, kernels, and native backends remain later work.
