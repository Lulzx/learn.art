# v0.12 — Resumable training state

v0.12 extends portable model checkpoints to the state required to resume optimization exactly.

## Added

- `optimizerState` and `loadOptimizerState` for SGD, Momentum, and Adam.
- Hyperparameter restoration for every optimizer.
- Momentum velocity and Adam first/second-moment buffer restoration.
- Adam timestep restoration for correct bias correction after resume.
- `saveTrainingCheckpoint` and `loadTrainingCheckpoint` for combined model and optimizer state.
- Cross-object atomic validation: neither model nor optimizer changes if either half is invalid.

## Validation

Optimizer kind, parameter count, slot count, slot shape, device, dtype, hyperparameter ranges, and timestep are validated before mutation. Slot tensors remain owned copies.

## Boundary

Training checkpoints do not yet store dataset position, shuffle state, epoch counters, gradients, runtime feeds, or graph source.
