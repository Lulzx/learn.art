# v0.21 — Evaluation telemetry

v0.21 adds full multiclass confusion telemetry for one-shot predictions and batchwise, mergeable validation.

## Confusion matrices

```arturo
matrix: confusionMatrix actual predicted
matrixWithKnownClasses: confusionMatrix.classes: 5 actual predicted
```

Rows represent actual classes and columns represent predicted classes. Without `.classes:`, the class count is one plus the largest observed index. Inputs must have equal shape, contain at least one value, and use non-negative integer-valued class indices.

The returned matrix is a float64 tensor, consistent with learn's tensor contract, even though internal meter counts remain integers.

## Reports

`classificationReport actual predicted` returns:

- overall `accuracy`;
- macro-averaged `macroPrecision`, `macroRecall`, and `macroF1`;
- a `perClass` row for every class with support, true positives, false positives, false negatives, precision, recall, and F1;
- the source confusion `matrix`.

Ratios with a zero denominator are defined as `0.0`. Explicit absent classes therefore participate in macro averages as zero, making fixed-class reports comparable across validation shards.

## Streaming and merging

```arturo
meter: confusionMeter 5
updateConfusion meter batchTargets batchPredictions
report: confusionReport meter
```

`mergeConfusion target source` adds counts and sample totals into `target`; both meters must have the same class count. This makes workers or separately evaluated shards reducible without retaining individual predictions.

`confusionState` returns an owned `learn.confusion-state` dictionary. `confusionFromState` validates class dimensions, non-negative integer counts, and the exact count sum before constructing independent meter storage.
