# v0.7 benchmark

Environment: Arturo 0.10.0, Apple arm64, Clang `-O3`, 1,024 sigmoid elements, 100 executions.

| Backend | Time |
|---|---:|
| Arturo reference | 1766.943 ms |
| Native fused CPU | 1369.102 ms |

This is an initial smoke benchmark, not a performance guarantee. CSV conversion and dynamic-library loading remain dominant overheads; the native path is presently a correctness-first backend contract.
