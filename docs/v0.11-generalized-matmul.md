# v0.11 — Generalized matrix multiplication

v0.11 extends `matmul` from rank-2 matrices to vector and broadcasted batch semantics.

## Added

- Vector dot products with scalar outputs.
- Matrix–vector and vector–matrix products with squeezed unit dimensions.
- Batched matrix multiplication for rank-2-or-higher tensors.
- Trailing-aligned broadcasting across leading batch dimensions.
- Direct reverse-mode accumulation across broadcasted batches.
- Eager and scheduled CPU parity for generalized output shapes.

## Shape rules

The final dimension of the left operand contracts with the second-to-last dimension of the right operand. A rank-1 left operand is promoted to a one-row matrix; a rank-1 right operand is promoted to a one-column matrix. Those promoted dimensions are removed from the result. All preceding dimensions broadcast using the ordinary tensor rules.

## Boundary

The reference implementation prioritizes exact semantics and gradient correctness. Native BLAS dispatch and accelerator-specific kernels remain future backend work.
