# v0.10 — Model state and checkpoints

v0.10 makes trained graph parameters portable without serializing executable graph code.

## Added

- `stateDict` for owned snapshots keyed by graph parameter name.
- Atomic `loadStateDict`, strict by default with explicit non-strict partial restoration.
- Shape, device, dtype, count, missing-name, unexpected-name, and duplicate validation.
- `saveCheckpoint` and `loadCheckpoint` using a compact Arturo-text data format.
- Parameter identity preservation, so existing optimizers and graph references remain valid after loading.

## Safety and portability

Checkpoint files contain a numeric format marker and positional data blocks. Loading uses Arturo's parser but never evaluates the parsed block. Tensor payloads continue to use the v0.9 `learn.buffer` contract and `float64` CPU storage.

## Boundary

v0.10 stores model parameters. Optimizer moments, graph source, runtime feeds, and gradients are not checkpointed.
