# v0.27 convolution gradients

v0.27 completes reverse-mode support for NCHW `conv2d`, `maxPool2d`, and `avgPool2d` in the eager reference engine. Convolution accumulates gradients for both NCHW inputs and OIHW weights. Pooling handles overlapping windows, stride, and padding using the same valid-element rules as the forward kernels.

The ordinary-data training pipeline needs no operation-specific optimizer changes. `differentiateGraph` emits an `automaticGradient` node for a convolution parameter, and `compileTraining` lets MPSGraph derive and execute that gradient. A compiled convolution test confirms the loss decreases while weights remain GPU-resident between steps.
