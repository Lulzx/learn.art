# v0.26 compiled autodiff

v0.26 makes compiled training a sequence of ordinary-data transformations:

```text
graphData -> differentiateGraph -> optimizerGraph -> MPSGraph compilation
```

`differentiateGraph data 'loss` optimizes the requested scalar-loss graph and appends one `automaticGradient` node per parameter. `optimizerGraph differentiated optimizer` appends SGD or momentum state and update nodes. Both return standard `learn.graph` dictionaries, so their nodes, edges, shapes, and update mappings can be inspected before compilation.

`compileTraining model 'loss optimizer` applies that pipeline and lowers the complete result through `arturo-metal`. A step returns the scalar loss while replacing GPU-resident parameter and optimizer-slot storage with the compiled program outputs. Model and optimizer state APIs provide explicit download and restore boundaries.

The older `compileMpsTraining.rate:.momentum:` schedule API remains supported and now delegates to the same transformations. Adam lowering and convolution/pooling reverse derivatives remain future work.
