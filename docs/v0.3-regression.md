# v0.3 — Regression layer

v0.3 builds useful estimators from the graph and autograd primitives without adding a second execution system.

## Added

- Differentiable sigmoid, exponential, logarithm, and binary cross-entropy.
- `fit.linear` and `fit.logistic` graph constructors.
- `predict`, probability prediction, `score`, `mse`, and `accuracy`.
- Deterministic paired train/test splitting with `split.ratio:`.
- Logistic fitting currently caps eager optimization at 200 epochs to remain
  stable on the Arturo 0.10 interpreter.
- Estimators default to 200 epochs; explicit smaller limits remain supported.

## Boundary

The initial estimators accept one feature per observation. Multivariate dense layers arrive with the neural-composition work in v0.4.
